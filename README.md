# 方块修理铺 · FIX & FIZZ

一个移动端优先、直接操作十件物品的原创 3D 小游戏。沿用 Blox 的方块结构、鲜明色块、三档明暗与彩色投影；在工作台上清洁、装配、接线、补胎、上弦、调音、缝补与浇水，还可以询问顾客故障、交还物件和收藏感谢卡。

## 十张维修单

- 小风扇：软毛刷扫除 7 处灰尘 → 安装四叶扇叶 → 拧紧两颗螺丝 → 长按通电，扇叶转动并吹起纸条。
- 收音机：安装天线和旋钮 → 把频率调整到绿色区域并稳定片刻 → 长按试听，播放合成旋律。
- 小机器人：匹配两块能量块 → 拧紧螺丝 → 长按唤醒，眼睛亮起、挥手回应。

零件可直接拖动，也可先点选再点接口。螺丝先放入孔位，再顺时针转动拧紧；也可以使用点按辅助，每次转四分之一圈。完成后可以按住查看原样。十件物品全部修好并交还后，可开启下一天，切换配色并重玩。没有倒计时或付费系统。

维修进度保存在当前浏览器的 localStorage；不同设备或不同域名之间不会同步。

## 本地运行

需要 Python 3 或任意静态 HTTP 服务器。

```sh
python3 -m http.server 4184 --directory dist
```

打开 `http://localhost:4184/`。不要直接双击 HTML，因为浏览器会限制本地 ES 模块的加载。所有 3D 引擎与模型均包含在包内，无运行时 CDN 依赖，无需安装 npm 依赖。

```sh
node qa/repair.test.mjs
```

## 实现

- Three.js + 原创几何模型，三档着色、自定义彩色投影、细描边。
- Pointer Events 统一触屏和鼠标操作；另有点选接口、滑条和长按辅助。
- 适配 320×568、400×580、390×844 竖屏与 844×390 横屏，桌面有收件单侧栏。
- 手机限制像素比和阴影分辨率，复用几何体和材质。
- Web Audio 合成擦拭提示、安装和拧紧提示、完成音阶、收音机旋律；首个操作后启用声音，静音开关控制所有音源。
- 主流程状态在 `dist/engine.js`，界面和输入在 `dist/main.js`，原创模型在 `dist/models.js`。
- Three.js 的 MIT 许可证见 `dist/vendor/THREE-LICENSE.txt`。无需外部模型授权。

## v2：维修手感与细节

- 污垢由持久化局部遮罩组成，擦过哪里才清掉哪里，保留部分清洁的痕迹。先喷泡沫，再用带手部模型的海绵来回擦；干擦较慢，按住不动不会擦掉污层。
- 沾湿会出现贴在物件表面的泡沫，擦拭时清掉泡沫和污层。清洁到 94% 后自动完成细小边缘残留，避免找不可见像素。
- 螺丝先拖到孔位，自动切近看镜头。可看到十字槽、螺纹、工具咬合和逐渐下沉。顺时针两圈拧紧，逆时针会松开。圆形手柄可拖动，也保留四分之一圈的点按辅助。
- 零件在接口附近有吸附提示，松开后沿轴向滑入并落位；安装完成后才推进流程。
- 加入喷气、干/湿摩擦、棘轮和金属落位合成音效，受原静音开关控制。
- 高频擦拭合并到每帧一次纹理更新，复用污层平面、泡沫粒子与螺丝几何。

v2 验证：在 400×580 浏览器视口实际完成风扇从清洁到通电的新版全流程；实测顺时针前进、逆时针退回、螺丝分颗放置、四分之一圈辅助、切换物件、泡沫保存，以及海绵按住不动不增加清洁进度。另检查小屏和横屏布局。v2 尚未在真实手机上测性能或扬声器听感。
